# IBM HR Analytics Dashboard – Looker Studio

## 📊 Project Overview

This project analyzes the IBM HR Analytics Employee Attrition & Performance dataset containing **1,470 employees**.

The dashboard was developed using **Google Looker Studio** to provide insights into employee attrition, demographics, income, job satisfaction, and other workforce characteristics.

## 🎯 Objectives

- Analyze overall employee attrition
- Identify employee groups with higher attrition
- Analyze attrition across age groups
- Understand the relationship between income and attrition
- Analyze job satisfaction levels
- Provide interactive HR insights for decision-making

## 🛠️ Tools & Technologies

- Google Looker Studio
- Microsoft Excel
- Data Cleaning
- Calculated Fields
- Data Visualization

## 📌 Key KPIs

- Total Employees
- Total Attrition
- Average Monthly Income
- Attrition Rate

## 📈 Dashboard Analysis

The dashboard includes analysis of:

- Employee Attrition
- Age Groups
- Income Brackets
- Job Satisfaction
- Department
- Job Roles
- Business Travel
- Overtime
- Employee Demographics

## 🔢 Calculated Fields

The project uses calculated fields including:

- Attrition Flag
- Attrition Rate
- Age Group
- Income Bracket
- Satisfaction Level

## 📂 Dataset

**Dataset:** IBM HR Analytics Employee Attrition & Performance

**Total Records:** 1,470 employees

The dataset contains employee demographics, job information, compensation, satisfaction levels, and attrition information.
